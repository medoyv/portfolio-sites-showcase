# medoyvmb / Web — интерактивное портфолио сайтов

Русскоязычный статический сайт с 16 самостоятельными демо-примерами. Карточки открывают отдельные страницы, которые можно изучать как обычные сайты.

## Запуск локально

Откройте index.html или запустите в папке проекта: python -m http.server 8000. Затем перейдите на http://localhost:8000.

Фильтры и поиск работают в каталоге. Демо содержат интерактивные карточки и локальную подборку. Они не передают данные на сервер. Сборка и сторонние библиотеки не нужны.

Контактная форма формирует письмо в почтовом приложении. Контакты взяты с прежнего портфолио: Telegram @medoyv, medoyv@vk.com, Kwork medoyv.

## GitHub Pages

В Settings → Pages → Build and deployment выберите GitHub Actions. Workflow в .github/workflows/pages.yml публикует статический сайт после обновления ветки main.
